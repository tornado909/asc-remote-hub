# Безопасное управление окнами Windows (агент 1.1.1)

В одной интерактивной сессии Windows все приложения используют общий указатель мыши и общее активное окно. Поэтому прежние координатные клики и ввод «в текущее окно» могут мешать пользователю. **ASC Remote Hub 1.1.1 по умолчанию блокирует такие действия.**

## Адресная работа через UI Automation

1. `window_list` выдаёт HWND, PID, заголовок и координаты окна.
2. `window_controls` читает дерево элементов строго указанного окна. Нужно передать HWND, `expected_pid` и `title_contains`. Курсор и клавиатура не используются.
3. `window_action` выполняет действие только над **единственным** найденным элементом по точному `automation_id` либо `name`. Дополнительные фильтры: `control_type`, `class_name`. Методы: `invoke`, `set_value`, `toggle`, `select`, `expand`, `collapse`.

Пример вызова `window_controls` (ID устройства, HWND, PID условные):

```json
{
  "device": "d_<из-list_devices>",
  "hwnd": 123456,
  "expected_pid": 4242,
  "title_contains": "Блокнот",
  "limit": 70,
  "depth": 6
}
```

После нахождения подходящего элемента:

```json
{
  "device": "d_<из-list_devices>",
  "hwnd": 123456,
  "expected_pid": 4242,
  "title_contains": "Блокнот",
  "selector": {
    "automation_id": "TextEditor",
    "control_type": "Edit"
  },
  "action": "set_value",
  "value": "Проверочный текст"
}
```

Если элемент не найден, неоднозначен или не поддерживает действие, инструмент возвращает ошибку. **Автоматического перехода к физическому клику нет.** Парольные поля недоступны.

## Защита работающего пользователя

Некоторые приложения самостоятельно перехватывают фокус при обращении через UI Automation. Это было воспроизведено на WPF.

- По умолчанию `window_action` разрешается, только если пользователь не работал с мышью и клавиатурой **не менее 45 секунд**. Проверка выполняется перед вызовом и непосредственно перед действием.
- Если окно неожиданно перехватило фокус, возвращается `UIA_FOCUS_INTERFERENCE`, а повторные UIA-действия с этим HWND/PID блокируются до перезапуска агента.
- Только просмотр `window_controls` не требует ожидания простоя.
- Оператор может настроить локальный параметр `ASC_RC_UIA_ALLOW_ACTIVE_USER=1`, но это снимает защиту пользователя. По умолчанию параметр выключен.

Фоновое UI Automation **не гарантирует абсолютной независимости** от интерактивной сессии: результат зависит от приложения. Для одновременной полноценной работы человека и агента нужен отдельный Windows-сеанс/рабочий стол либо API приложения.

## Старые средства ввода

`click_mouse`, `type_text`, `press_keys`, `scroll_mouse`, `terminal_send`, `window_focus` в Windows **запрещены по умолчанию** даже при полном доступе агента.

Для их включения администратор должен локально задать `ASC_RC_ALLOW_INTERACTIVE_GUI=1` и отдельно разрешить вмешательство в конкретном вызове через `allow_desktop_interference=true`. Обязательны точные HWND, PID и часть заголовка. Клавиатурный/мышиный ввод допустим только в уже активное окно. Самовольное переключение фокуса комбинацией Alt больше не применяется.

Не включайте интерактивный режим, если за компьютером продолжает работать человек.

## Ограничения и проверки

- Electron, Chromium, игры и другие приложения с нестандартной графикой могут не предоставлять доступных элементов UI Automation. Ошибка не является разрешением нажать в приблизительные координаты.
- `window_screenshot` пока захватывает прямоугольник с экрана, который может содержать перекрывающие окна. Для адресных действий важнее дерево UI Automation.
- Отправка `invoke` не доказывает завершение операции приложения. Проверяйте состояние после действия; `set_value` проверяет текст там, где это поддерживается.
- `run_command` работает с правами пользователя ОС и не ограничивается GUI-защитой: доступ к выполнению команд следует выдавать осознанно.

Обновление: `npx --yes https://hub.example.com/cli.tgz`. Версия агента **1.1.1**. После обновления проверьте `machine_info.agent_version` и выполните обновление списка MCP-инструментов в приложении.

Тесты находятся в `tests/test_gui_safety.py`. Не проверяйте физические клики на рабочем столе, за которым сейчас работает человек.
