# ASC Remote Hub для Android 0.4.0

Android 11 и новее. Root, ADB и Shizuku не требуются. Скачайте подписанный APK с вашего сервера по пути /downloads/asc-remote-hub-android.apk. Пройдите мастер первого запуска: включите уведомления, службу специальных возможностей, доступ к общим файлам и режим батареи «Без ограничений». После автоматической проверки всех четырёх разрешений укажите HTTPS-адрес собственного сервера (например https://hub.example.org), получите в его личном кабинете одноразовый код привязки (10 минут), введите его в приложении и подтвердите доступ. При обновлении с 0.3.0 и новее существующая привязка сохраняется. При переходе со старых экспериментальных сборок без сохранённого адреса сервера требуется новая привязка. Для смены сервера сначала отзовите старую привязку и подключитесь с новым кодом. Токен никогда не переносится между серверами. HTTP и URL с путями не поддерживаются; настройки доступны с главного экрана. На новых Android при установке APK может понадобиться вручную разрешить ограниченные настройки в сведениях приложения.

После привязки агент самостоятельно поддерживает исходящее HTTPS-соединение, получает команды через /agent/next, восстанавливает соединение и запускается после загрузки Android. Android может ограничить фоновое соединение при Doze, после принудительной остановки или при ограничениях производителя. Управление интерфейсом доступно только на включённом разблокированном экране, через дерево Accessibility, без скриншотов. Не все приложения предоставляют доступное дерево. Парольные поля исключены. Запуск приложений требует Accessibility. Доступ к приватным каталогам других приложений отсутствует.

Команды: machine_info, list_directory, stat_path, android_apps, android_launch, android_ui_tree, android_ui_action, android_gesture, android_file_read, android_file_write. Для файлов используется Base64 и смещения байтов, до 65536 байт на операцию; offset=0 создаёт новый файл, продолжение требует точного размера. Для UI используйте свежий snapshot и node_id. Команды back/home/recents не требуют node_id. Остановить работу можно в приложении или уведомлении, отозвать привязку — в приложении или Hub.

Исходники: android/. Сборка: android/build.sh, JDK 17, SDK 35 и build-tools 35.0.0. Ключ подписи хранится отдельно от исходников и опубликованного APK. Не переносить его в архивы дистрибутива. На Android 17 проверены подключение, чтение дерева и вертикальные сенсорные свайпы. Горизонтальные свайпы, перетаскивание и мультитач требуют отдельного тестирования.

## Сенсорные жесты

Получите свежий android_ui_tree: snapshot, screen_width, screen_height. В android_gesture передайте snapshot и strokes. Каждый stroke содержит points (координаты x/y в пикселях экрана), duration_ms и необязательный start_ms. Один пункт — нажатие или удержание, несколько — свайп или перетаскивание. До пяти одновременных касаний, одинаковый start_ms для мультитача. Например, свайп вверх: {"snapshot":"...","strokes":[{"points":[{"x":500,"y":1600},{"x":500,"y":600}],"duration_ms":400}]}. После каждого жеста обновляйте дерево. При смене окна/ориентации старый snapshot отклоняется. Экран должен быть разблокирован. Жесты могут прервать локальное касание.
