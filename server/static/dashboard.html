Отвязать или удалить ASC Remote Hub

Выполните команду на том компьютере, где установлен агент (Windows PowerShell или Linux). Сайт не удаляет программы удалённо.

Отвязать устройство

Отозвать его ключ на текущем хабе, остановить автозапуск и удалить локальную привязку. Приложение останется для подключения к другому хабу.

Удалить агент

Отозвать привязку, остановить агент и удалить установку, настройки и журналы текущего пользователя. Остальные программы и устройства не затрагиваются.

Обе операции запросят локальное подтверждение. Если старый хаб недоступен, добавьте --local-only. Тогда не забудьте отдельно отозвать устройство на старом сервере. Для просмотра плана используйте --dry-run.

Приватность и диагностика

По умолчанию сохраняются счётчики и краткие причины ошибок. Полные тексты команд и файлов могут записываться только в отдельно включённом режиме диагностики.

Другие пользователи не видят ваши устройства и данные. Администратор сервера несёт ответственность за безопасность инфраструктуры.

Подключение MCP-приложений

Один ASC Remote Hub для ChatGPT, Cursor, OpenMausBot и других MCP-клиентов. Укажите HTTPS-адрес в настройках Streamable HTTP MCP нужного приложения и пройдите OAuth-авторизацию под своей учётной записью.

В Cursor: mcp.json → . В ChatGPT: добавить собственный MCP-сервер. Пароли и ключи агентов приложениям не передаются.

После OAuth-подключения каждое приложение видит только ваши устройства и выданные им разрешения.
