Нет Node.js или Python?

Сначала установите зависимости. Действующая установка агента и привязка не затрагиваются.

Команда проверки зависимостей

Также можно скачать автоматический установщик, проверить его текст и запустить локально. Он установит недостающие компоненты и запустит подключение. Для Linux npm/npx не требуются. При установке пакетов могут потребоваться права администратора.

После скачивания запустите файл в PowerShell.

Windows: для проверки CLI используйте --dry-run. Linux: для проверки скачанного bootstrap-скрипта используйте --check, для проверки пакета и окружения --cli-dry-run. Сам агент работает на Python без Node.js.

Вставьте код в терминал. Он действителен 10 минут; никому его не передавайте.

Чтобы получить код привязки, зарегистрируйтесь или войдите в свой аккаунт ниже.

Отвязать или удалить ASC Remote Hub

Выполните команду на том компьютере, где установлен агент (Windows PowerShell или Linux). Сайт не удаляет программы удалённо.

Отвязать устройство

Отозвать его ключ на текущем хабе, остановить автозапуск и удалить локальную привязку. Приложение останется для подключения к другому хабу.

Удалить агент

Отозвать привязку, остановить агент и удалить установку, настройки и журналы текущего пользователя. Остальные программы и устройства не затрагиваются.

Обе операции запросят локальное подтверждение. Если старый хаб недоступен, добавьте --local-only. Тогда не забудьте отдельно отозвать устройство на старом сервере. Для просмотра плана используйте --dry-run.
