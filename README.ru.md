**Один собственный хаб. Ваши компьютеры. Разные MCP-клиенты.**

> [!NOTE]
> **Независимый open-source проект.** Не связан с OpenAI, Cursor, OpenMausBot и Desktop Commander. Хаб не устанавливает платных квот на вызовы, но сами MCP-клиенты могут иметь собственные ограничения.

## Что это

ASC Remote Hub — **многопользовательский сервер Model Context Protocol (MCP)** для подключения ИИ-ассистентов к вашим компьютерам. Сервер принимает запросы по стандартному **Streamable HTTP**, авторизует пользователя через OAuth и передаёт команды агентам Windows или Linux.

Хаб работает в Docker, использует SQLite и хранится на вашем сервере. Агенты сами устанавливают **исходящее HTTPS-соединение**. Публиковать RDP, SSH или отдельные порты агентов в интернете не требуется.

### Возможности

| Функция | Что доступно |
| --- | --- |
| **Файлы** | Просмотр каталогов, пакетное чтение, поиск текста, метаданные, создание и изменение файлов в разрешённых каталогах. |
| **Команды** | Запуск программ, фоновые процессы, сбор вывода и диагностика системы. |
| **Рабочий стол** | Снимки экрана, поиск и активация окон, адресный ввод в терминал Windows при активной пользовательской сессии. |
| **Разные MCP-клиенты** | ChatGPT, Cursor, OpenMausBot и другие совместимые приложения с авторизацией OAuth. |
| **Разделение пользователей** | Личные устройства, токены, права, журнал ошибок и статистика по аккаунтам. |
| **Диагностика** | Метрики задержек, журналы и настраиваемая полная трассировка запросов. |

## Как это работает

```text
    ChatGPT      Cursor     OpenMausBot    Другие MCP-клиенты
       \           |            |               /
        \__________|____________|______________/
                           |
                 Streamable HTTP + OAuth
                           |
                  +------------------+
                  |  ASC Remote Hub  |
                  |  Python + SQLite |
                  |  Учётные записи  |
                  +------------------+
                     ^           ^
           исходящий HTTPS   исходящий HTTPS
                     |           |
              Windows-агент   Linux-агент
              Файлы/консоль   Файлы/процессы
              Рабочий стол
```

Перед каждым вызовом сервер проверяет аккаунт и принадлежность устройства. Агент ограничивает доступ своими локальными разрешениями. Специальный транспорт ChatGPT или туннель OpenAI не нужен.

## Быстрый старт

Потребуются **Linux**, **Docker Compose**, собственный домен и HTTPS-сертификат с reverse proxy (либо Caddy из комплекта).

**1. Скачайте и настройте проект:**

```bash
git clone https://github.com/tornado909/asc-remote-hub.git
cd asc-remote-hub
cp .env.example .env
```

В `.env` укажите свой домен:

Канонический публичный адрес хаба задаётся через `ASC_HUB_URL`.

```dotenv
ASC_HUB_URL=https://hub.example.com
ASC_HUB_DOMAIN=hub.example.com
ASC_BIND_IP=127.0.0.1
ASC_BIND_PORT=18765
PUID=1000
PGID=1000
ASC_HUB_TRACE_PAYLOADS=0
```

**2. Запустите сервер:**

```bash
mkdir -p data
chmod 700 data
docker compose up -d --build hub
```

Настройте HTTPS-прокси на `127.0.0.1:18765` либо запустите Caddy (если порты 80 и 443 свободны):

```bash
docker compose --profile public up -d --build
```

**3. Откройте** `https://hub.example.com`, создайте учётную запись и получите одноразовый код подключения устройства.

Подробнее: [инструкция по развёртыванию](docs/DEPLOYMENT.md).

## Подключение компьютера

Запустите **одну и ту же команду без номера версии** в PowerShell или терминале Linux, заменив адрес на свой:

```shell
npx --yes https://hub.example.com/cli.tgz
```

Установщик проверит контрольную сумму агента, попросит код привязки и разрешения и настроит автозапуск. Требуются **Node.js 18+**, **Python 3.10+** и `tar`. Node.js для постоянной работы агента не нужен.

На Windows PowerShell:

```powershell
npx --yes https://hub.example.com/cli.tgz
```

Проверка без установки:

```shell
npx --yes https://hub.example.com/cli.tgz --dry-run
```

- **Windows:** агент в системном трее, автозапуск через планировщик, дополнительное управление графическим интерфейсом. Журналы: `%LOCALAPPDATA%\ASC-Remote-Hub\logs`.
- **Linux:** служба systemd пользователя или системная служба при установке от root. Не выдавайте права исполнения от root без необходимости.

> [!CAUTION]
> Ограничения каталогов защищают встроенные файловые инструменты. **Запущенные программы работают с правами учётной записи агента**, если разрешён `run_command`. Начинайте с режима «только чтение».

## Подключение MCP-клиентов

Общий URL для приложений с поддержкой удалённого Streamable HTTP MCP:

```text
https://hub.example.com/mcp
```

В браузере авторизуйтесь под **своей учётной записью ASC Remote Hub**. Для OAuth используется PKCE; поддерживается регистрация HTTPS callback веб-клиентов и loopback callback локальных приложений.

### Cursor

Добавьте сервер в уже существующий объект `mcpServers` файла `mcp.json`:

```json
{
  "mcpServers": {
    "asc-remote-hub": {
      "url": "https://hub.example.com/mcp"
    }
  }
}
```

Глобальный путь Windows: `%USERPROFILE%\.cursor\mcp.json`. **Не удаляйте ранее настроенные серверы.** Затем пройдите авторизацию OAuth в Cursor.

### ChatGPT

Добавьте собственный MCP-сервер с адресом `https://hub.example.com/mcp` и авторизуйтесь на странице Hub.

### OpenMausBot и другие агенты

Выберите удалённый MCP-сервер типа **Streamable HTTP**, укажите URL хаба и пройдите OAuth. Жёсткого списка разрешённых брендов больше нет. Конкретные действия в интерфейсе зависят от MCP-клиента.

> [!TIP]
> В личном кабинете раздел **«Авторизованные MCP-приложения»** позволяет отозвать токены отдельного клиента, не отключая устройства и другие приложения.

## Безопасность

- **OAuth + PKCE S256**, отдельные токены доступа и обновления, обязательное подтверждение доступа пользователем.
- **Dynamic Client Registration** с HTTPS-адресами возврата или loopback HTTP для локальных приложений; redirect URI проверяется на точное совпадение.
- **Изоляция пользователей**: чужие устройства и токены недоступны.
- **Локальные разрешения агента**: чтение, запись, выполнение команд и управление GUI.
- **Только исходящий HTTPS со стороны агентов**, уникальные ключи устройств; в Windows секреты защищены DPAPI.
- **Полная трассировка**: при `ASC_HUB_TRACE_PAYLOADS=1` включается для всех аккаунтов и может содержать команды, файлы и скриншоты. Хранилище необходимо защищать.
- **Нет сквозного шифрования от администратора хаба**: владелец сервера с полными правами может исследовать трафик.

Устанавливайте агенты только на принадлежащих вам устройствах или с разрешения владельца. Подробности: [политика безопасности](SECURITY.md).

## Версии и ограничения

| Компонент | Версия |
| --- | --- |
| Сервер Hub | **1.2.0** |
| Агенты Windows / Linux | **1.1.0** |
| Установщик CLI | **1.1.0** |
| MCP | Streamable HTTP |
| Авторизация | OAuth + PKCE + DCR |

При обновлении серверной части 1.2.0 существующие агенты 1.1.0 **не нужно перепривязывать**.

Текущие ограничения: один серверный процесс и очередь задач в памяти; фоновые процессы могут терять идентификаторы после перезапуска агента; GUI нужен активный сеанс Windows; объёмы файловых операций ограничены. OAuth Client ID Metadata Documents пока не реализованы, используйте клиентов с Dynamic Client Registration.
